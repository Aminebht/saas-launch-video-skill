# Narratives: the story shapes

Pick one per direction. Times are for a 45 s cut; scale for 30 s (cut the middle) or 60 s (add a feature beat). Roles map to HyperFrames blueprint roles (Hook, Problem, Product_Intro, Key_Feature, Benefits, Social_Proof, CTA, Brand_Outro). `hyperframes-creative/references/story-spine.md` and `beat-direction.md` go deeper.

## 1. Problem → shift → proof → outcome
For products that remove a clear pain.
| Time | Beat |
| --- | --- |
| 0-5 | Hook: the pain, felt (too many tabs, a messy spreadsheet, a late invoice) |
| 5-9 | Shift: the product appears; one line of promise |
| 9-30 | Proof: 2-3 real actions in the UI, each changing the state |
| 30-38 | Outcome: the number, the result screen, the happy end state |
| 38-45 | Brand outro + CTA |

## 2. One workflow, start to finish
For products whose value is the flow itself. One task, shown end to end, in near real time.
| Time | Beat |
| --- | --- |
| 0-3 | Hook: the task in one line ("Bill a client in 20 seconds") |
| 3-36 | The workflow: start state, input, the product working, edits, done (camera follows the cursor) |
| 36-41 | Result in the world (sent, live, paid) |
| 41-45 | Logo + URL |

## 3. Feature cascade
For platforms with 3-5 strong features. Claim, proof, claim, proof.
| Time | Beat |
| --- | --- |
| 0-4 | Hook / product intro |
| 4-36 | 3-4 × (claim 1-1.5 s, then UI proof 5-7 s) |
| 36-41 | Everything else (bento, pill wall, constellation) |
| 41-45 | Outro |

## 4. Before / after
For products that transform an artefact (a page, a report, a design).
| Time | Beat |
| --- | --- |
| 0-6 | Before: the old way, slow or ugly (split screen or one side) |
| 6-10 | The switch (one action) |
| 10-34 | After: the same task, fast, with the product; split-screen comparisons |
| 34-45 | The difference in a number + outro |

## 5. Speed run
For speed or automation claims. A visible timer drives the film.
| Time | Beat |
| --- | --- |
| 0-3 | "From X to Y in N seconds" + a timer at 00:00 |
| 3-35 | The run, with the timer always on screen; the camera keeps up |
| 35-40 | Timer stops; result |
| 40-45 | Outro |

## 6. Teaser / manifesto
For pre-launch or brand moments. Promise-led; the UI appears only late.
| Time | Beat |
| --- | --- |
| 0-25 | 5-8 short statements over strong visuals (type, 3D object, abstract product details) |
| 25-38 | The product revealed in one hero shot |
| 38-45 | Name, date or CTA |

## 7. Customer story
For products where trust sells. One persona's day.
| Time | Beat |
| --- | --- |
| 0-5 | Who they are (photo or illustration + caption) |
| 5-12 | Their problem in their words (pull quote) |
| 12-35 | How they use the product (UI beats) |
| 35-41 | Their result (quote + metric) |
| 41-45 | Outro |

## Rules for any narrative
- **Show real product actions.** Every claim needs UI proof within a few seconds.
- **One idea per beat.** Hold text ≥ 0.5 s + 0.25 s per extra word.
- **The first 3 seconds must earn the next 3** (motion, a question, or a striking number).
- **End on something to do or remember** (URL, logo, CTA), not on a feature.
